# 🍁 메이플 랜덤 디펜스 가이드

스타크래프트 유즈맵 **메이플 랜덤 디펜스**용 데스크톱 가이드 프로그램입니다.
뽑은 유닛(**고스트·히드라·드라군**)을 카운트하고 목표 스테이지를 고르면,
**데미지 타입 × 적 크기 배율**과 몬스터 스탯(체력/방어력/쉴드/쉴드방어력/체젠)을 계산해
지금 **어떤 유닛을 키우고/팔고, 무엇을 업그레이드해야 하는지**를 알려줍니다.

## 게임 메커니즘

뽑는 유닛은 3종이며 각자 공격형이 다릅니다.

| 유닛 | 공격형 | 소형 | 중형 | 대형 | 특징 |
|------|--------|------|------|------|------|
| 고스트 | 진동형 | 100% | 50% | 25% | 소형 물량 특화 |
| 히드라 | 노말형 | 100% | 100% | 100% | 모든 크기 무난(만능) |
| 드라군 | 폭발형 | 50% | 75% | 100% | 대형/보스 특화 |

스테이지마다 소형/중형/대형 적이 정해진 순서로 출현하며, 중간중간 **보스 스테이지**가 있습니다.

### 데미지 공식

```
HP 데미지   = max(minDamage, 공격력 × 크기배율 − 방어력)
쉴드 데미지 = max(minDamage, 공격력 − 쉴드방어력)      ← 쉴드는 크기배율을 무시
```

- 쉴드가 있으면 쉴드를 먼저 깎은 뒤 HP를 깎습니다.
- **체젠(HP 재생)**이 초당 가하는 HP 데미지보다 크면 그 유닛으로는 **처치 불가**(체젠 벽)로 표시·경고합니다.

## 주요 기능

- **유닛 카운팅 / 판매** — 뽑으면 `+`, 팔면 `−`. 종료 후에도 자동 저장.
- **스테이지 선택** — 목표 스테이지를 고르면 등장 적과 스탯을 표로 표시.
- **유닛별 처치 시간(TTK)** — 각 적을 유닛 1기가 몇 초에 잡는지(처치 불가 포함) 계산.
- **이번 스테이지 최적 유닛** — 적 크기/스탯 기준 가장 효율적인 유닛을 추천.
- **업그레이드 우선순위** — 현재 스테이지에서 *비용 대비 화력 증가*가 가장 큰 업그레이드.
- **판매 조언** — 앞으로 올 스테이지에서 효율이 없는(처치 불가/배율 낮은) 유닛을 짚어줌.
- **데미지 배율표** — 진동/노말/폭발 × 소형/중형/대형 참조표 상시 표시.

> 카운팅은 현재 **수동 클릭** 방식입니다. 추후 화면 자동 인식(OCR)을 별도 단계로 추가할 수 있습니다.

## ⚠️ 데이터에 대하여

`data/` 의 수치는 **예시(placeholder)** 입니다. 실제 게임 값으로 교체하면 추천이 정확해집니다.

| 파일 | 내용 |
|------|------|
| `data/units.json` | 유닛 (공격형/공격력/쿨다운/판매가/업그레이드 연결) |
| `data/enemies.json` | 몬스터 (크기/체력/방어력/쉴드/쉴드방어력/체젠/보스여부) |
| `data/stages.json` | 스테이지별 등장 적과 수량, 보스 스테이지 |
| `data/upgrades.json` | 유닛별 공격력 업그레이드 (레벨당 증가/비용) |
| `data/meta.json` | 크기 정의, 데미지 배율표, 최소 데미지 |

### 데이터 형식 예시

```jsonc
// units.json
{ "id": "ghost", "name": "고스트", "damageType": "concussive",
  "damage": 20, "cooldown": 1.0, "atkUpgrade": "ghost_atk", "sellValue": 50 }

// enemies.json
{ "id": "golem", "name": "바위 골렘", "size": "large",
  "hp": 320, "armor": 3, "shield": 0, "shieldArmor": 0, "hpRegen": 2 }

// stages.json
{ "stage": 8, "name": "8 - 혼성", "boss": false,
  "spawns": [ { "enemy": "orc", "count": 8 }, { "enemy": "golem", "count": 6 } ] }
```

크기 배율은 `meta.json` 의 `sizeModifiers` 에서 자유롭게 조정할 수 있습니다.

## 추천 엔진 동작 요약

1. **유닛 1기 vs 적 1기**: 데미지 공식으로 한 대당 데미지 → 쉴드/HP 차례로 처치하는 **TTK** 계산(체젠 반영).
2. **유닛 가치** = (쉴드+HP) / TTK 를 스테이지 적 수로 가중 합산. 처치 불가면 0.
3. **최적 유닛** = 이번 스테이지에서 가치가 가장 높은 유닛.
4. **업그레이드 추천** = `+1레벨 시 화력 증가량 ÷ 다음 비용` 이 큰 순.
5. **판매 조언** = 앞 스테이지들에서 가치가 0인 보유 유닛.
