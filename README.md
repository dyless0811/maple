# 🍁 메이플 랜덤 디펜스 가이드

스타크래프트 유즈맵 **메이플 랜덤 디펜스**용 데스크톱 가이드 프로그램입니다.
유닛을 뽑을 때마다 카운트하면, **현재 보유 유닛과 업그레이드 상태에 맞춰 최적의 선택(합성/업그레이드/보강)**을 실시간으로 알려줍니다.

## 주요 기능

- **유닛 카운팅** — 뽑은 유닛을 `+ / −` 로 기록. 종료 후에도 자동 저장.
- **합성 추천** — 같은 유닛이 합성 개수에 도달하면 상위 등급 승급을 안내.
- **업그레이드 우선순위** — 현재 진영 기준 *비용 대비 화력 증가가 가장 큰* 업그레이드를 추천.
- **진영 분석** — 지상/공중 대상 화력, 물리/마법 데미지 비중을 막대로 표시하고 약점을 경고
  (예: 공중 화력 부족 시 공중 보스 취약 경고).
- **보유 유닛 화력** — 업그레이드가 반영된 실효 DPS를 유닛별로 표시.

## 실행 방법

```bash
npm install     # Electron 설치
npm start       # 앱 실행
npm test        # 추천 엔진 단위 테스트
```

> 인터넷이 차단된 환경에서는 `npm install`(Electron 다운로드)이 실패할 수 있습니다.
> 추천 엔진 로직은 `npm test`로 의존성 없이 검증할 수 있습니다.

## ⚠️ 데이터에 대하여

`data/` 폴더의 유닛·업그레이드 수치는 **예시(placeholder)** 입니다.
실제 게임 수치를 모르기 때문에 합리적인 가상 데이터로 채워 두었습니다.
실제 메이플 랜덤 디펜스 데이터로 교체하면 추천이 정확해집니다.

| 파일 | 내용 |
|------|------|
| `data/units.json` | 유닛 목록 (등급/공격대상/데미지타입/DPS/시너지/합성) |
| `data/upgrades.json` | 업그레이드 트리 (적용 대상/레벨당 증가/비용) |
| `data/meta.json` | 등급(티어) 정의, 분석 임계값 |

### 유닛 데이터 형식

```json
{
  "id": "swordman",          // 고유 ID (영문)
  "name": "검사",             // 표시 이름
  "tier": 1,                  // 등급 (meta.json의 tiers와 연동)
  "attackType": "ground",    // ground | air | both
  "damageType": "physical",  // physical | magic
  "dps": 32,                  // 기본 초당 화력
  "synergy": ["전사"],        // 시너지/계열 태그
  "combineCount": 3,          // 합성에 필요한 개수 (0이면 합성 없음)
  "combinesTo": "knight"      // 합성 결과 유닛 ID (없으면 null)
}
```

### 업그레이드 데이터 형식

```json
{
  "id": "ground_atk",
  "name": "지상 공격력",
  "appliesTo": { "attackType": ["ground", "both"] },  // 적용 조건 (유닛 필드와 매칭)
  "maxLevel": 20,
  "perLevel": 0.08,        // 레벨당 +8%
  "baseCost": 100,
  "costGrowth": 1.25       // 레벨당 비용 증가율
}
```

## 프로젝트 구조

```
maple/
├── main.js            # Electron 메인 프로세스 (창 생성, 데이터/상태 IPC)
├── preload.js         # 렌더러에 안전한 API 노출
├── src/
│   ├── index.html     # UI
│   ├── styles.css     # 스타일 (다크 테마)
│   ├── renderer.js    # UI 렌더링 & 상호작용
│   └── engine.js      # 추천 엔진 (브라우저/Node 공용)
├── data/              # 게임 데이터 (수정 가능)
└── test/              # 엔진 단위 테스트
```

## 추천 엔진 동작 요약

1. **실효 DPS** = 기본 DPS × ∏(1 + 레벨 × 레벨당증가) — 적용되는 모든 업그레이드 반영.
2. **합성 추천** = 보유 개수 ≥ 합성 개수인 유닛을 등급 상승 우선으로 정렬.
3. **업그레이드 추천** = `+1레벨 시 총 화력 증가량 ÷ 다음 레벨 비용` 이 큰 순서.
4. **진영 분석** = 화력의 지상/공중·물리/마법 비중을 계산해 약점을 경고.
